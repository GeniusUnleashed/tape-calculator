# Tape Calculator

A compact calculator for the Mac with a paper tape: a running record of every number entered and every result, like the tape on an adding machine.

## Download

The latest version is on this repository's Releases page. Download the disk image, open it, and drag Tape Calculator to the Applications folder. The app is signed and notarized by Apple.

Requires macOS 14 Sonoma or later.
